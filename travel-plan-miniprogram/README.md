# 旅游攻略检索生成微信小程序

## 项目简介

这是一个基于微信小程序的旅游攻略检索和生成应用，旨在为用户提供便捷、个性化的旅游规划服务。

## 核心功能

1. **首页展示**：热门目的地推荐、热门攻略展示、核心功能入口
2. **攻略检索**：多条件筛选（目的地、出行天数、人群、兴趣偏好、预算）
3. **路线规划**：集成百度地图，支持步行、公交、自驾、骑行路线规划
4. **攻略生成**：基于用户参数智能生成个性化旅游攻略
5. **个人中心**：用户登录、攻略管理、收藏管理
6. **攻略详情**：展示详细攻略内容，支持收藏和分享

## 技术栈

- 微信小程序原生开发
- 百度地图 API（集成中）
- AI 大模型 API（集成中）

## 快速开始

1. 克隆项目到本地
2. 使用微信开发者工具打开项目
3. 配置百度地图 API Key 和 AI 大模型 API Key（在 app.js 中）
4. 编译并运行小程序

## 功能说明

### 首页
- 搜索框：输入目的地检索攻略
- 热门推荐：展示热门目的地
- 核心功能入口：生成攻略、路线规划、我的收藏
- 热门攻略：展示浏览量高的攻略

### 攻略检索
- 多条件筛选：支持按目的地、出行天数、人群、兴趣偏好、预算筛选
- 搜索结果：展示符合条件的攻略列表

### 路线规划
- 路线类型：支持步行、公交、自驾、骑行
- 地图展示：集成百度地图
- 路线详情：显示详细的路线步骤

### 攻略生成
- 参数设置：目的地、出行天数、人群、预算、兴趣偏好等
- 攻略内容：生成包含行程安排、景点介绍、餐饮推荐、注意事项的完整攻略

### 个人中心
- 用户登录：微信授权登录
- 我的攻略：管理自己生成的攻略
- 我的收藏：管理收藏的攻略
- 设置：清除缓存、关于我们、意见反馈

### 攻略详情
- 详细内容：展示攻略的完整内容
- 收藏功能：收藏/取消收藏攻略
- 分享功能：分享攻略到微信好友和朋友圈

## 注意事项

1. 本项目使用了模拟数据，实际使用需要集成真实的百度地图 API 和 AI 大模型 API
2. 需要在微信开发者工具中配置合法的 AppID
3. 部分功能需要用户授权地理位置信息
