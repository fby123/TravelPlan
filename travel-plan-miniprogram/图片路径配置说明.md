### 2. 图片路径规则

#### 微信小程序图片路径规则：

1. **tabBar图标**：
   - 必须使用本地图片（不支持网络图片）
   - 路径格式：`images/文件名.png`（相对于项目根目录）
   - 图片格式：png
   - 推荐尺寸：81px × 81px
   - 文件大小：不超过40KB

2. **页面内图片**：
   - 支持本地图片和网络图片
   - 本地图片路径格式：`/images/文件名.jpg`（以/开头的绝对路径）
   - 网络图片路径：完整的URL地址

### 3. 修改其他页面的图片路径

如果需要修改其他页面的图片路径，请遵循以下步骤：

1. **打开页面的wxml或js文件**
2. **找到图片引用位置**
3. **将路径修改为正确的本地路径**

示例（在wxml文件中）：
```html
<!-- 修改前 -->
<image src="https://example.com/image.jpg"></image>

<!-- 修改后 -->
<image src="/images/your-image.jpg"></image>
```

示例（在js文件中）：
```javascript
// 修改前
data: {
  image: 'https://example.com/image.jpg'
}

// 修改后
data: {
  image: '/images/your-image.jpg'
}
```

### 4. 注意事项

1. **图片尺寸限制**：
   - tabBar图标：81px × 81px
   - 页面图片：根据设计需求确定，但建议不超过200KB

2. **文件格式**：
   - tabBar图标：必须使用PNG格式
   - 页面图片：支持PNG、JPG、JPEG、GIF等格式

3. **路径格式**：
   - 在wxml中引用本地图片时，路径以`/images/`开头
   - 在app.json的tabBar配置中，路径直接写`images/文件名`（开头不带/）

4. **网络图片**：
   - 如果需要使用网络图片，在微信开发者工具中需要配置合法域名
   - 在“详情” → “本地设置”中勾选“不校验合法域名”（仅用于开发环境）

### 5. 添加新图片的步骤

1. 将图片文件放入 `images/` 目录
2. 在代码中引用图片，使用正确的路径格式
3. 在微信开发者工具中刷新项目查看效果

## 开发调试技巧

1. **在微信开发者工具中预览**：
   - 打开微信开发者工具
   - 导入项目文件夹 `travel-plan-miniprogram`
   - 点击“编译”按钮查看效果

2. **检查图片是否正确加载**：
   - 在开发者工具中查看“Network”面板
   - 检查图片资源的状态，确保没有404错误

3. **替换tabBar图标**：
   - 如果需要更换tabBar图标，确保新图标符合尺寸和格式要求
   - 更新 `app.json` 中的图标路径

## 常见问题解决

1. **图片不显示**：
   - 检查图片路径是否正确
   - 确认图片文件是否在 `images/` 目录中
   - 在开发者工具的“调试器”中查看是否有错误提示

2. **tabBar图标不显示**：
   - 确认图片路径在 `app.json` 中是正确格式（开头不带/）
   - 检查图片格式是否为PNG
   - 确认图片大小是否在限制范围内

3. **路径格式错误**：
   - 在wxml中：使用 `/images/文件名`
   - 在app.json的tabBar中：使用 `images/文件名`
   - 在js数据绑定中：使用 `/images/文件名`
